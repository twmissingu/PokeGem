# PokeGem E2E 测试清单

> **Scope**: 人工 QA 测试清单。覆盖 UI 布局、交互流程、游戏规则的人工验证场景。
> 游戏逻辑规则已通过 247 个自动化单元测试覆盖（Swift Testing），不需要通过此清单回归。
> 规则定义见 [game-rules.md](game-rules.md)，技术实现见 [design.md](design.md)。

---

## 测试环境
- 设备: iPhone 17 Simulator
- 系统: iOS 26.3
- 测试模式: 横屏优先，竖屏兼容

## 五、交互功能测试

### 5.1 拿取宝石 (Take Coins)
- [ ] 点击宝石计数器选中该颜色（0→1→2→0 循环）
- [ ] 选中的宝石有绿色环 + 发光效果
- [ ] 可以选 3 个不同颜色各1个
- [ ] 可以选 2 个相同颜色（当该颜色≥4）
- [ ] 可以选 1 个（当不满3个时）
- [ ] 超过 10 个上限时提示错误 Toast
- [ ] 选中2个时显示绿色 "2" 徽章
- [ ] 「确认」按钮完成拿取
- [ ] 「取消」按钮清空选择

### 5.2 购买卡牌 (Purchase Card)
- [ ] 点击卡牌弹出 Sheet 详情
- [ ] Sheet 显示卡牌图片、成本（扣除折扣后）、点数
- [ ] 资源足够时「购买」按钮可用
- [ ] 资源不足时「保留」按钮可用
- [ ] 购买后卡牌从桌面补充
- [ ] 购买后Toast显示成功

### 5.3 保留卡牌 (Reserve Card)
- [ ] 点击卡牌有「保留」选项
- [ ] 保留后卡牌移到玩家保留区（底部保留卡条）
- [ ] 保留时获得黄金宝石（桌面有且未达上限时）
- [ ] 保留区最多 3 张卡
- [ ] 保留满后不能继续保留

### 5.4 贵族拜访 (Noble Visit)
- [ ] 满足条件时点击贵族卡可获得
- [ ] 不满条件时点击显示 info Toast
- [ ] 贵族卡从桌面移除
- [ ] 玩家分数增加 3 分

### 5.5 保留卡偿还 (Repay)
- [ ] 点击底部保留卡条中的卡牌选中
- [ ] 资源足够时「偿还」按钮可用
- [ ] 偿还后卡牌变为发展卡

### 5.6 玩家面板交互
- [ ] 点击玩家头像以 Sheet 查看详情
- [ ] 详情页显示总分、持有宝石、发展卡、保留卡、贵族卡
- [ ] 「关闭」按钮返回游戏

## 六、游戏规则验证

### 6.1 Setup 规则
- [ ] 根据人数设置宝石数量 (2人:4个/色, 3人:5个/色, 4人:7个/色)
- [ ] 金币固定 5 个
- [ ] 贵族卡数量正确 (n+1, 最多10)
- [ ] 卡牌展示正确 (每层4张)

### 6.2 回合规则
- [ ] 玩家轮流行动
- [ ] 行动后自动轮到下一位
- [ ] AI 自动执行动作
- [ ] AI 快进按钮支持 2×/4×/8× 加速

### 6.3 胜利规则
- [ ] 达到目标分数后完成当前轮再结束
- [ ] 分数相同时比较贵族数
- [ ] 贵族再相同时比较卡牌数
- [ ] 显示胜利者界面（排名列表）
- [ ] 「再来一局」按钮重新开始
- [ ] 「返回主页」按钮回到主菜单
